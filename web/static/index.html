1. The System Call Boundary (User Space to Kernel Space)

┌────────────────────────────────────────────────────────────────────────┐ │ USER SPACE (Ring 3 - Unprivileged) │ │ User Application -> glibc wrapper: write(fd, buf, count) │ │ Registers Setup: %rax=1 (sys_write), %rdi=fd, %rsi=buf, %rdx=count │ │ CPU Instruction: 'syscall' │ └───────────────────────────────────┬────────────────────────────────────┘ │ CPU Mode Switch (Ring 3 -> Ring 0) ┌───────────────────────────────────▼────────────────────────────────────┐ │ KERNEL SPACE (Ring 0 - Privileged) │ │ Syscall Dispatcher: sys_call_table[%rax] │ │ sys_write() -> VFS: vfs_write(file, buf, count, pos) │ │ Device / Filesystem Driver -> Page Cache / Hardware Controller │ │ CPU Instruction: 'sysret' -> Mode Switch back to Ring 3 │ └────────────────────────────────────────────────────────────────────────┘
